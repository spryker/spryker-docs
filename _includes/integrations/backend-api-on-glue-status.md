The Glue-based Backend API infrastructure is deprecated; [API Platform](/docs/integrations/spryker-api/api-platform/api-platform.html) is the recommended infrastructure for new development. The Backend API application currently serves its endpoints on Glue: API Platform already supports the `backend` API type, but the Backend API modules shipped by Spryker have not been migrated yet. For the current per-module state, see [Migration status - Glue API to API Platform](/docs/integrations/spryker-api/migrate-from-glue-to-api-platform/migrate-to-api-platform-status.html).
