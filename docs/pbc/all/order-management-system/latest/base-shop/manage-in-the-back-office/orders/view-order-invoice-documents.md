This document describes how to open the [invoices](/docs/pbc/all/order-management-system/latest/base-shop/order-management-feature-overview/order-invoice-documents-overview.html) of an order in the Back Office.

## Prerequisites

The order must have a generated invoice. An invoice is generated by triggering the `invoice-generate` event on a confirmed order. For details, see [Change the state of order items](/docs/pbc/all/order-management-system/latest/base-shop/manage-in-the-back-office/orders/change-the-state-of-order-items.html).

## Viewing order invoice documents

1. Go to **Sales&nbsp;<span aria-label="and then">></span> Orders**.
    This opens the **Orders** page.
2. Next to the order you want to check, click **View**.
    This opens the **Order Overview** page.
3. Scroll to the **Documents** block. The invoices of the order are listed with their reference and date. In marketplace shops, the block also shows the merchant of each invoice.
4. In the **Files** column, click **PDF**.
    The invoice page opens in a new browser tab. To save the invoice as a PDF file, click **Save as PDF** and select the PDF printer in the print dialog.

Orders without an invoice show *No documents for this order*.

### Reference information: Viewing order invoice documents

| ATTRIBUTE | DESCRIPTION |
|---|---|
| Reference No. | Reference of the invoice, for example `Invoice-12`. |
| Date | Issue date of the invoice. |
| Merchant | Marketplace shops only: the merchant the invoice was issued for. The invoice for the items sold by the marketplace operator shows an empty cell. |
| Files | The **PDF** link that opens the invoice page. |
